# Soldier001

Prototyp gry 2D w Unity tworzony w celach nauki.

## Założenia projektu
- Silnik: **Unity 6 (6000.4.11f1)**
- Template: **Universal 2D (URP)**
- Język: **C#**
- Workflow: **Git + GitHub**
- Edytor kodu: **VS Code + GitHub Copilot**

## Sposób pracy
Projekt rozwijam na podstawie tutorialu.  
Kod (klasy, metody i nazwy) może być celowo zbliżony lub taki sam jak w materiale źródłowym, aby łatwiej śledzić naukę krok po kroku.

## Struktura (na start)
- `Assets/` – skrypty, sceny, grafiki, prefaby
- `Packages/` – pakiety Unity
- `ProjectSettings/` – ustawienia projektu

## Uruchomienie
1. Otwórz projekt w Unity Hub.
2. Użyj wersji edytora: **6000.4.11f1**.
3. Otwórz główną scenę i uruchom Play Mode.
